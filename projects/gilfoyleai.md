A two-part AI impersonation system (Chrome extension + Python server) that uses Google's Gemini Flash 2.0 to read Discord chat history and auto-type responses, emulating the user in conversation. The Chrome extension scrapes the last 5 messages, sends them to Gemini, then delegates keystroke simulation to a local Python server — a creative (and admittedly janky) workaround for Discord's page automation restrictions.
